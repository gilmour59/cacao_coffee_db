# October 23 demo flow: quick operator guide

Use the [final presenter script](OCT_23_PRESENTATION_SCRIPT_AND_FLOW.md) for spoken lines. This page is the click checklist for the presentation computer. **TEST only; all showcased records are fictional.**

## Windows to prepare

- **Private/incognito window:** [TEST farmer page](https://script.google.com/macros/s/AKfycbxXQYYjRgumA18liMmxwUSbj_K_A0Lm4f9-n3kYVSU5Z22otMyFI51KzHvFYTrWnAWX/exec). New farmers and existing farmers with a valid private link do not need a Google account.
- **Regular signed-in window:** [TEST staff app](https://script.google.com/macros/s/AKfycbwWozzUZEtZmYuX4gP9KQgZRc-fPmNwDyqU-wwcKdOlUl0NnW0z-0ZfUp6uwZ7VxDiR/exec). Use the TEST Admin account for this script. A third profile is optional if showing a separate Encoder or Validator sign-in.
- **Optional hidden tab:** A personal TEST invitation for synthetic farmer `DEMO-F-2026-002`, with **Synthetic farm 002** selected. Do not display, shorten, or print its token URL.

## Rehearsal checks

1. Open both URLs and confirm the farmer window opens without Google sign-in, while the staff window shows the expected role.
2. On the farmer page, confirm the yellow testing notice appears. Visit the new-farmer form, then return Home. **Review Summary** is optional; **Submit for Validation** performs the required checks.
3. In staff **Existing Farmer Links**, search `DEMO-F-2026-002`; choose year, purpose, and a specific farm before generating a link. A secure link is tied to one farmer; the base farmer URL is not.
4. If opening that synthetic link, confirm its permitted farmer details, Shallow Well water source, Coffee/Robusta profile, and Storage shed facility load. For a new annual year, a prior-year harvest should not become a new harvest by default.
5. Open **Validator Queue** and explain that submission is pending until a Validator approves it or returns it with a reason. Keep personal details off the projector.
6. Open **Live Dashboard**, select 2026, and wait for the first load. Try Crop → Province → Municipality → Barangay filters; show the municipality map, production trend, and support sections. The display reads the private TEST Sheet, refreshes every two minutes while open, and shows elapsed loading seconds. It contains fictional seed data, not official field statistics.
7. Only if separately rehearsed end to end: submit a fresh fictional profile, approve it through the authorized TEST Validator, and click **Refresh** to show a visible count change. Do not claim that change until it appears on screen.

## If something fails

- **Sign-in prompt on farmer page:** Check that the farmer URL above, rather than the staff URL, was opened in the private window.
- **Wrong staff role:** Use the prepared Admin window; do not change access settings during the presentation.
- **Slow dashboard or storage error:** Let the loader run, retry **Refresh** once, then continue with visible sections. An offline synthetic preview is a backup only; label it as disconnected from the Sheet.
- **Private token or personal details appear:** Switch back to Home immediately and continue verbally.

## What to say clearly

> “This is a demonstration and testing version. The records shown today are fictional and are not official farmer submissions or field statistics. The system needs more testing and institutional approval before operational use.”
